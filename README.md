Un programa para registrar datos de clientes.
Lista principal: contiene todos los datos de los clientes registrados.
Se genera una sub-lista por cada cliente. 
Cada sub-lista contiene: nombre, apellido y correo electrónico.
El usuario ingresa los datos solicitados.
Se añade la sub-lista a la lista principal.

Archivo de texto:
- después de añadir la sub-lista a la lista principal, automáticamente se guarda la información en un archivo de texto.
- se usa "w": crea un archivo nuevo o sobrescribe uno existente.
- dada la acción de guardar automáticamente, si se da un inconveniente de conexión, la información estará guardada.
- el archivo inicial muestra en un archivo ee texto cada cliente en una línea: '[name, lastname, email]


Cambio propuesto:
- practicar otra forma en que quede presentada la información en el archivo de texto: 'name, lastname, email'.
- de esta manera es tiene otra presentación para su lectura.
